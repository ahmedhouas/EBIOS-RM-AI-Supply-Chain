# Contribution Guidelines

## General Rules

1. Keep documents in their corresponding folders.
2. Use clear and consistent file names.
3. Pull the latest main branch before starting work.
4. Do not overwrite another member's work without coordination.
5. Do not commit passwords, credentials or private keys.
6. Update CHANGELOG.md for significant project changes.

## Branch Naming

- docs/project-planning

- docs/bcp-update

## Collaboration Workflow

1. Update your local main branch.
2. Create a working branch.
3. Make and save your modifications.
4. Commit changes with a descriptive message.
5. Push your branch to GitHub.
6. Create a Pull Request.
7. Obtain the required review.
8. Merge approved changes into main.

## Document Ownership

The two designated document reductors/editors
coordinate workshop consolidation and final documents.

Technical content must be validated by the relevant
analyst before final publication.
